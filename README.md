# World Models for Autonomous Driving

Static project page for the survey **World Models for Autonomous Driving: From Future Generation to Decision Making**.

## Local preview

Open `index.html` directly in a browser. No build step or package installation is required.

## Content source

The page content, PDF, bibliography, figures, method evidence codes, and author metadata are synchronized with:

`E:\.survey\World Models for Autonomous Driving_10.27`

The deployed paper is stored at `assets/World-Models-for-Autonomous-Driving.pdf`.

All seven figures cited in the manuscript are rendered from the source PDFs and stored alongside their original PDFs in `assets/figures/2026-10-27`. Only blank page margins are cropped. `assets/source-manifest.json` records the source and output SHA-256 hashes for verification.

The methods table follows the three current manuscript tables: 29 temporal world models and one static boundary comparator. The vector/graph cross-reference is not double-counted.

The site uses a blue-and-white layout and a local, licensed Lucide bundle. No third-party CDN is required. Publish the repository root from the `main` branch on GitHub Pages.
